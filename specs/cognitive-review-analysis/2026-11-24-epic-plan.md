# Epic Plan: Cognitive Pipeline Coherence

**Parent Epic:** Cognitive Pipeline Coherence — unified composition, verified integration

---

## Parallelism model

The constraint is git merge conflicts when branches merge to main. Different Maven modules = zero conflict risk. Same module, different files = low risk (pom.xml edits are the exception). Same file = conflict.

**CognitionCore.java is the bottleneck.** 14 findings require changes to this single file. These must be resolved first (SE1). Everything else is organized around this constraint.

## SE1: Pipeline Spine

**Module:** cognition (core files), cognition-api
**Files:** CognitionCore.java, CognitionCoreFactory.java, CognitivePipelineBuilder.java, CognitionDefaultBeans.java, DirectiveSection.java, CognitionConfig.java
**Blocks:** SE6, SE7

### Child issues

**1. CognitionConfig builder pattern** (A1, A13)
Replace 28-positional-boolean record with builder or EnumSet. `all()` and `withAllSubsystems()` must produce the same config — one composition path for production and tests.

**2. Per-agent cognitive state** (A3, C19, D13)
Key all `last*` fields by (agentId, tenantId). `promptSections()` takes agent/tenant args. Scope LLM session ids by tenant. Move `updateBase` to only-when-descriptor-changes (eliminates per-tick cache invalidation).

**3. Pipeline builder completeness** (A2, A6, A7, A8, D7)
Wire all `configure*` methods into the builder. Fix gut-feeling/retriever ordering (A7). Fix tenant resolution at build time (A8). Fix DirectiveSection SimpleName lookup after entity wrapping (A6). Fix frozen `Instant.now()` in recency decay producer (D7).

**4. Stale appraisal and double-tick** (C1, C8)
Clear appraisal result on no-observation ticks — stop re-bridging stale state to mood/drives. Remove duplicate `drives.tick()` call (line 376 vs 415).

**5. CognitionCore quality signal and dead code** (E2, E3, E11)
Fix interaction quality timing (read mood after exchange, not before). Either wire `configureTheoryOfMind` or remove dead code. Replace regex JSON parsing with proper parser.

## SE2: CAPS Rework

**Modules:** caps-engine, caps-testing, caps-llm-classifier, caps-situation-cbr
**Plus:** BehavioralSynthesisPhase.java, ClassificationOutcomeEvaluator.java (in mindmap-intelligence — exclusively owned by this epic)
**Parallel with:** everything

### Child issues

**1. Settler baseline and activation** (B1, B4, B5, B6)
Fix unipolar node baseline (0.5 background swamps input). Make resting activation a persistent bias in net input, not just initial condition + post-hoc addition. Fix distortion sign-agnostic application. Tighten convergence variance threshold.

**2. Weight learning** (B2, B3, B15)
Fix update rule (target node must appear, multi-cue competition). Wire learning results so `saveState` is called after `updateWeights`. Fix precision tracking to match Pearce-Hall or document the variant.

**3. Topology validation and state** (B7, B8, B16, B17)
Add topology loader validation (warn on disconnected nodes). Add topology/disposition version to persisted state. Add settler unit tests that assert input CHANGES output — not just attractor presence.

**4. Classification pipeline** (B9, B10, B11, B12, B13, B14)
Fix outcome evaluator (not constant per-agent). Fix CBR cache id (use hit's id, filter on all fields). Wire keyword classifier or remove dead code. Fix BehavioralSynthesisPhase input filtering. Fix threshold multiplier base (non-zero). Fix LLM classifier session reuse (stateless per classification).

## SE3: Storage & Data Integrity

**Modules:** memory-sqlite, mindmap-sqlite, mindmap
**Parallel with:** everything

### Child issues

**1. Memory cursor ordering** (F1)
Replace `UUID.randomUUID()` with monotonic ID (ULID, snowflake, or auto-increment) for `memory_id` in SQLite and JPA stores. This is the most critical data integrity bug — skips memories permanently.

**2. MindMap query correctness** (F4)
Apply trait filter in SQL (or at minimum apply LIMIT after Java-side filtering). Fix subgraph type vs id confusion in callers.

**3. Confidence decay and derived edges** (F12, F20)
Read per-type half-life from vocabulary registration. Refresh decay reference on reinforcement. Persist derived-edge truth maintenance state across restarts.
