# Cognitive Capability Matrix

Every cognitive capability in the neocortex architecture, mapped to trigger conditions,
environmental requirements, observable outputs, and duration needs.

Purpose: design game scenarios that naturally exercise the full cognitive stack.

## Environmental Requirements Summary

### Minimum viable game environment must provide:

1. **Multiple characters** with distinct personality profiles (different PID-5 facets, disposition axes, goals)
2. **Perceivable events** that vary in novelty, relevance, and controllability
3. **Social interaction** between characters — cooperation, competition, conflict
4. **Goal-relevant challenges** — obstacles, opportunities, choices with consequences
5. **Temporal structure** — enough ticks for consolidation cycles, relationship evolution, personality drift
6. **Ambiguity** — situations where intentions are unclear, forcing Theory of Mind
7. **Value/belief challenges** — events that contradict established beliefs or force value tradeoffs
8. **Relationship dynamics** — trust building, betrayal, alliance formation and dissolution
9. **Variable intensity** — both calm periods (for decay/reflection) and high-intensity situations (for regulation/coping)
10. **Recurring themes** — topics that return without full resolution (for recurring thought detection)

### Capabilities NOT exercisable without specific structures:

| Capability | Required structure |
|-----------|-------------------|
| Cognitive dissonance (8.3) | Characters must encounter evidence contradicting their beliefs or be forced to act against their values |
| Goal decomposition (4.2) | Goals must be complex enough to have sub-goals — simple "survive" isn't enough |
| Belief revision (7.1) | Beliefs must exist AND evidence must contradict them — needs a belief-then-disconfirm arc |
| Social norm detection (5.8) | Enough agents doing similar things that patterns emerge — needs group-level behavioral regularity |
| Recurring thought (8.4) | Same unresolved topic must recur across multiple ticks without resolution |
| Shadow archetypes (6.5) | Extreme sustained pressure — normal gameplay won't trigger shadow unless stakes are very high |
| Strategy learning (7.4) | Enough varied interactions with measurable outcomes — needs both success and failure |
| Relationship stage evolution (5.5) | Enough positive OR negative interactions to shift from one relational stage to another — needs ~10+ interactions |

### Tick budget estimates for key arcs:

| Arc | Minimum ticks | Why |
|-----|:------------:|-----|
| Emotion → regulation visible | ~5-10 | Single intense event + regulation response |
| Drive → goal proposal | ~10-20 | Drive must build, then exceed threshold |
| Goal → plan → execute → outcome | ~30-50 | Multi-step with sub-goals and obstacles |
| Relationship: stranger → ally | ~30-50 | Needs repeated positive interactions |
| Relationship: ally → betrayal → enemy | ~20-30 | Trust built then violated |
| Relationship: enemy → reconciliation | ~50-80 | Hardest arc — needs sustained positive despite negative history |
| Belief formation → contradiction → revision | ~40-60 | Belief must consolidate, then be challenged |
| Personality drift visible | ~100+ | Personality evolves very slowly by design |
| Social norm emergence | ~50+ | Needs enough repeated group behavior |
| Full cognitive dissonance arc | ~20-40 | Value established → forced violation → tension → resolution |
| Recurring thought → fixation | ~30-50 | Same topic must recur without resolution multiple times |
